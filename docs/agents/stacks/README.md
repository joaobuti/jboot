# Stack References

Este diretorio e um catalogo tecnico por familia de stack.

## Regra

Arquivos daqui nao sao executores principais quando a tarefa tem `target_project` em `implementations/*`.

Use estes documentos para:

- comparar stacks em decisoes arquiteturais;
- criar ou atualizar agents locais de projeto;
- revisar se um agent local esta coerente com a stack;
- apoiar o `architect` antes de confirmacao humana.

Para projeto novo, o catalogo deve ser usado como espaco de comparacao por fit do escopo. Baseline do repositorio nao e escolha automatica. Se a entrega for site estatico, documentacao, portfolio, landing ou marketing tecnico com pouca interatividade, comparar Astro antes de recomendar Next.js.

Execucao concreta deve acontecer pelos agents locais declarados em `implementations/<project>/PROJECT_CONTRACT.md`.
