# Skill Local: pdv-mobile-ui

## Uso

Aplicar em telas mobile/tablet do PDV.

## Regras

- Seguir `docs/design-system.md`.
- Usar componentes nativos equivalentes, nao componentes web.
- Priorizar area de toque, leitura rapida e baixa friccao.
- Estados offline/sync devem ser visiveis.
- A venda deve continuar mesmo sem rede.
