# Skill Local: local-storage-contract

## Uso

Aplicar ao modelar SQLite local do app PDV.

## Regras

- Tabelas locais devem ser versionadas.
- Dados locais devem ter origem/sync status.
- Eventos locais devem ser append-only ate confirmacao.
- Migrations locais devem ser testaveis.
- Dados sensiveis devem ser minimizados.
