# Skill: api-contract

## Objetivo

Manter APIs da platform alinhadas a contratos.

## Procedimento

1. Verificar OpenAPI/contrato do modulo antes de implementar.
2. Se endpoint/campo nao existir no contrato, atualizar contrato antes do codigo.
3. DTOs devem refletir contrato.
4. Erros devem ser estruturados.
5. Validar compatibilidade com clients web/app.
