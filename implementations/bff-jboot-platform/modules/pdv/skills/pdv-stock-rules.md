# Skill: pdv-stock-rules

## Objetivo

Padronizar regras de estoque do PDV.

## Procedimento

1. Toda movimentacao deve ter origem, tipo e contexto.
2. Saldo deve ser calculavel/auditavel.
3. Ajuste manual exige motivo.
4. Importacao deve manter rastreabilidade por linha.
5. Conflitos offline devem ser tratados como eventos de reconciliacao.
