# Skill: pdv-crud

## Objetivo

Padronizar CRUDs do modulo PDV na backend platform.

## Procedimento

1. Confirmar contrato OpenAPI.
2. Criar DTOs validados.
3. Criar controller/service/repository por recurso.
4. Filtrar todas as queries por `client_id`.
5. Auditar mutacoes relevantes.
6. Validar lint, typecheck e build.
