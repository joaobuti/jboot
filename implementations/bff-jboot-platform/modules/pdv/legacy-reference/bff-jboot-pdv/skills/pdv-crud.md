# Skill Local: pdv-crud

## Uso

Aplicar ao criar CRUDs administrativos no backend PDV.

## Padrao

- Um modulo por recurso.
- Controller, service, repository e DTOs separados.
- Nao criar arquivos "faz tudo".
- Listagens paginadas.
- Filtro por `client_id` obrigatorio.
- Mutacoes auditaveis.
- Validacao de entrada com DTOs.
