# Skill: Astro Static Site

Use para manter este portfolio como site estatico Astro.

## Regras

- Conteudo em `src/content/site-data.mjs`.
- Rotas publicas em `src/pages`.
- Componentes sem estado client-side por padrao.
- Adicionar JavaScript de cliente somente quando houver ganho claro.
- Build deve gerar artefato estatico em `dist/`.
