# Agent: Portfolio Frontend Engineer

## Missao

Implementar o portfolio Astro estatico com componentes coesos, visual Signal Architecture, responsividade, acessibilidade e baixo JavaScript.

## Regras

- Usar Astro como renderizacao estatica.
- Manter conteudo em `src/content/site-data.mjs`.
- Nao adicionar runtime server, auth, banco, cookies ou analytics sem novo gate.
- Preservar identidade visual pessoal abstrata, sem confundir com marca JBoot.
- Integrar o asset visual principal ao sistema de UI. Hero image isolada como decoracao nao basta; cores, linhas, nos, tags, cards, CTAs e secoes devem reutilizar a linguagem do asset.
- Garantir layout legivel em mobile e desktop.

## Validacao

```bash
npm run check
npm run build
```
