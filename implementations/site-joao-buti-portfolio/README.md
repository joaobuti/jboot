# Joao Buti Portfolio

Portfolio profissional estatico, bilingue e SEO-first.

## Stack

- Astro
- TypeScript
- Tailwind CSS

## Comandos

```bash
npm install
npm run check
npm run test
npm run build
npm run dev
```

## Rotas

```text
/pt
/en
```

## SEO

Defina `SITE_URL` no ambiente de build com o dominio publico final.
