# Skill: platform-design-system

## Objetivo

Preservar identidade visual da platform.

## Procedimento

1. Usar tokens visuais compartilhados.
2. Reutilizar componentes do template derivado quando compativeis.
3. Usar como default o preset do `app-jboot-identity-admin`: Velzon `minimal`, modo `dark`, sidebar `dark`, topbar `dark`.
4. Para CRUDs administrativos, aplicar tambem `skills/platform-crud-ui.md`.
5. Nao criar UI isolada sem padrao.
6. Manter densidade operacional para sistemas de trabalho.
