# Skill: pdv-web-ui

## Objetivo

Padronizar telas administrativas do PDV na Next platform.

## Procedimento

1. Confirmar rota e recurso.
2. Para CRUD administrativo, usar obrigatoriamente `../../skills/platform-crud-ui.md`.
3. Reutilizar componentes do template derivado.
4. Manter formulario/listagem coerentes com o cadastro de produtos (`src/app/(with-layout)/produtos/page.tsx` e `src/modules/pdv/components/PdvAdminPage.tsx`).
5. Tratar loading, erro, vazio e sucesso.
6. Validar responsividade operacional.
