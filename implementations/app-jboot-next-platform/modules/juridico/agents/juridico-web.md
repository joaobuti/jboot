# Agent: Juridico Web

## Responsabilidade

Garantir UI do portal jurídico dentro da Next platform: menu de portais contratados, estados ativo/bloqueado, consultas e configuração de credenciais.

## Regras

- Telas devem seguir contrato do BFF jurídico.
- Menu deve refletir portais contratados pelo tenant — bloqueados visíveis, nunca ocultos.
- Layout deve herdar shell e design system da platform.
- Rotas prefixadas em `/juridico/*`.
