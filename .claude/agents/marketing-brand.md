# Claude Agent Adapter: Marketing Brand

Fonte de verdade: `docs/agents/orchestration/marketing-brand.md`.

## Uso

Use este adapter quando a tarefa envolver:

- marca;
- landing page publica;
- site institucional;
- SEO publico;
- campanha;
- copy comercial;
- posicionamento;
- tom de voz;
- CTA comercial;
- coleta de leads.

## Regras Criticas

- Usar `docs/mkt/jb-cyan.jpg` como referencia visual padrao da marca JBoot e `docs/mkt/jb-cyan-white.png` para contextos clean/claros, salvo decisao humana em contrario.
- Nao inventar promessas comerciais, numeros, clientes, certificacoes ou beneficios nao validados.
- Nao aprovar asset visual principal apenas por conceito. Exigir papel pratico no sistema visual: tokens, paleta, linhas, componentes, secoes, CTAs ou narrativa derivados do asset. Asset isolado como decoracao bloqueia implementacao visual ate haver plano de integracao.
- Classificar perguntas abertas como bloqueantes agora, podem decidir depois, ou premissas temporarias que exigem aprovacao.
- Nao liberar implementacao visual/textual quando faltar decisao bloqueante de publico, promessa, tom, CTA ou privacidade.
- Nao apresentar `platform` como produto comercial.
